
# Meezan Builders Real Estate Management System

A web-based real estate management application designed to help manage property listings, client information, and customer inquiries in one place.

## Features

- Add, view, edit, and delete property listings
- Manage property details, prices, locations, and status
- Upload and display property images
- Manage client records and leads
- Search and filter properties
- Dashboard for property management

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Getting Started

1. Clone this repository.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open `http://127.0.0.1:5000` in your browser.

## Purpose

This project was developed to practice web development, database management, and real-world business workflow automation.
